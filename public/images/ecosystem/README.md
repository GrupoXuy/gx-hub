## Regras de uso (não negociáveis)

- Usar o arquivo oficial de cada empresa, sem recriar, recortar ou alterar cores.
- Manter a proporção original: o componente usa `object-fit: contain`, sem distorção nem filtros.
- Formato preferido: PNG com fundo transparente, lado maior com no mínimo 256px.
- Se a logo tiver fundo sólido (ex.: arte quadrada), ela será exibida integralmente dentro do quadro 40×40 com fundo grafite — sem cortes.
- Enquanto o arquivo não existir, o card exibe automaticamente o ícone neutro de fallback (Lucide), sem quebrar o layout.

Nenhuma mudança de código é necessária após adicionar os arquivos: basta colocá-los aqui e republicar.
